# Agent Loop workspace instructions

This file is the entrypoint for instructions in this repository. Agent Loop loads it automatically at the start of every run, from the workspace directory or the nearest parent that contains it, and then loads the documents it links to. No other file in this repository is loaded automatically.

- [Workflow orchestration](WO.md): how work is planned, verified and reported.
- [context-mode routing rules](instructions/context-mode.md): tool routing to follow when context-mode MCP tools are available.

These instructions grant no tools, approvals or paths. The runtime's own rules take precedence over them.
